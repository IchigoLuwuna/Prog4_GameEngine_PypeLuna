## Controls

### Keyboard

This control scheme attempts to emulate how you would rest your hands on an arcade machine
General:
> A/D for moving left/right
> J/K for shooting

Utilities:
> F1 to skip a level
> F2 to (un)mute the audio
> Return to advance to the next screen

### Controller

General:
> D-Pad or joystick for movement
> Cross (PS)/A (XB)/B (Nintendo) for shooting
> Start to advance to the next screen
